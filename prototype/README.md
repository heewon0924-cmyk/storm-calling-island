# 1차 프로토타입

**여는 법: `index.html`을 브라우저로 엽니다.** 설치도 서버도 필요 없습니다.

기획서 [01번 §14](../docs/01_게임_시스템_설계원칙.md)의 1차 프로토타입 범위입니다.
그래픽·사운드는 없습니다. **기획이 재미있는지만** 확인하는 도구입니다.

## 무엇을 검증하려고 만들었는가

[12번 §5](../docs/12_복선_회수표.md)가 지정한 첫 검증 항목입니다.

> **"다음 회차를 시작하게 만드는 힘"이 실제로 작동하는가.**
> S급 복선 25개 중 21개가 CASE 2에 있으므로, 이것이 작동하지 않으면 주제가 도달하지 않는다.

## 들어 있는 것

| | |
| --- | --- |
| 플레이어블 | **에드워드 · 에밀리 · 토머스** (엘레나는 CASE 2 비중이 커서 제외) |
| 조사 대상 | 마이클 · 알렉산더 · 헨리 · 대니얼 · 엘레나 |
| 장소 | 7곳 |
| 동사 | 이동(무료) · 조사 · 관찰 · 질문 · 제시 · 조회 · 대조(무료) |
| 예산 | **행동 12회**, 1회 = 30분, 23:20 → 05:20 섬 도착 |
| 사실 | 23개 (12번 회수표의 CASE 1 구간) |
| 끝 | 처분 판단 → 캐릭터별 혼잣말(얕은/깊은) → 회차 누적 |

**수첩은 회차를 넘어 누적되고, 캐릭터의 지식은 매 회차 초기화됩니다.**
지난 회차에 알아낸 것은 흐리게 보이고 쓸 수 없습니다 — *답을 아는데 증명할 수 없는* 상태가 이 게임의 핵심 루프입니다. ([06번 §3](../docs/06_플레이어_행동_설계안.md))

## 파일

```
index.html   화면 구조
style.css    표시
data.js      ← 콘텐츠 전부. 엔진과 분리되어 있어 다른 엔진으로 그대로 옮길 수 있다
game.js      규칙만. 이야기를 모른다
```

**새 단서·인물·대사를 넣을 때는 `data.js`만 고칩니다.**

## 알려진 수정 이력

**1차 측정에서 후크가 거꾸로 걸려 있었습니다** — 사다리를 끝까지 올라간 회차가 *"확인하지 못한 채 섬에 내린 것: 없다"* 로 끝났습니다. 후크 5개가 전부 사다리 바깥 경로에 있었기 때문입니다.

사다리 위에 후크 두 개를 세워 고쳤습니다. 둘 다 새 설정이 아니라 이미 문서에 있던 문장입니다.

* **벽 하나 건너였는데, 누구인지 모른다** — 헨리의 증언과 함께 나온다
* **이것으로는 그를 그 방에 넣을 수 없다** — 필체 대조와 함께 나온다

→ 가장 깊이 간 회차가 **가장 센 후크**로 끝납니다. *다 맞혔는데 증명이 안 된다.*
