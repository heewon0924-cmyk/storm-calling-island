# 1. 필체 견본 5종 🔑

> **이 게임에서 가장 중요한 자산입니다.** [06번 §3](./06_플레이어_행동_설계안.md)이 대조를 *"이 게임의 심장"* 이라고 했고, 그 심장이 이 다섯 장입니다.
>
> 🔴 **AI로 만들 수 없습니다.** 글씨를 일관되게 못 씁니다. **종이에 직접 쓰고 폰으로 찍으세요.**

## 이 다섯 장이 성립시켜야 하는 것

```
H-1 A. Wade      ┐
                 ├─ 같은 손으로 읽혀야 한다   ← 이 게임의 진실
H-4 A. Morgan #3 ┘

H-2 · H-3 · H-4  ─ 서로 다른 손으로 읽혀야 한다   ← "손이 세 개다"

H-3 ≡ H-5        ─ 같은 손 (마이클)              ← 필체 일치
```

**같은 손의 근거는 「기울기」와 「획을 끊는 자리」입니다.** 게임 안에서 그렇게 설명합니다.

> 앞의 것은 또렷하고 뒤의 것은 흔들린다. 그런데 **기울기가 같다. 획을 끊는 자리가 같다.**

## 실제로는 세 사람이면 됩니다

§16-C에 *"네 사람의 손"* 이라고 적혀 있는데 **세 사람이 맞습니다.**

| | 누가 쓰나 |
| --- | --- |
| H-1 · H-4 | **같은 사람** (아서 역) — 20년의 차이만 손에 담습니다 |
| H-2 | 다른 사람 (헨리 역) |
| H-3 · H-5 | 또 다른 사람 (마이클 역) |
