# CASE 2 — 섬과 저택 구조

> **이 문서 전체가 [제안]입니다.**
> 장소는 배경이 아니라 시스템입니다. **동사 7개**([06번](./06_플레이어_행동_설계안.md))와 **행동 12회 제한**, **캐릭터별 접근 차이**에 맞물리도록 설계합니다.

---

# 0. 설계 원칙

1. **장소 수는 8곳.** 더 늘리면 12회로는 훑지도 못하고, 줄이면 선택의 압박이 사라집니다
2. **모든 장소에 조사 대상이 1~3개.** 총 16개 안팎 → **12회로는 절반밖에 못 봅니다**
3. **모든 장소에 캐릭터 제한이 걸립니다.** 4명이 각각 다른 섬을 보게 됩니다
4. **중심이 하나 있어야 합니다** — 이 섬에서는 **절벽**입니다

## 시간 제한 [제안]

CASE 1이 *"섬에 도착할 때까지"* 였다면, CASE 2는:

> **폭풍이 지나고 배가 다시 올 때까지.**

섬에 도착한 순간부터 구조선이 도착할 때까지가 조사 시간입니다. **행동 12회.**

                    └──────┬──────┘

    ┌─────┴─────┐   ┌──────┴──────┐   ┌────┴─────┐

    └───────────┘   │  ② 응접실      │   │  (별채)  │
                    │  ③ 식당        │   └────┬─────┘
                    │  ④ 서재        │        │

                    └───────┬────────┘   ⑥-b 아서의 방

                      ┌─────┴─────┐
                      │  ① 부두   │  ← 도착 / 구조선
                      └───────────┘

# 2. 장소별 설계

## ① 부두

배가 닿는 곳. 시작이자 끝.

| | |
| --- | --- |
| **조사 대상** | 정박 기록 / 리처드의 짐 (배에서 내려진 것) |
| **접근** | 전원 |
| **숨겨진 것** | **리처드의 짐 안에, 그가 배에 가져오지 않은 나머지 자료**가 있습니다. 그는 전부 들고 타지 않았습니다 |

> 마이클은 배 위에서 훔친 한 장이 전부라고 믿고 있습니다. **아닙니다.**

## ② 응접실 — 중심

사람들이 모이는 곳. 아무도 혼자 있고 싶어 하지 않습니다.

| | |
| --- | --- |
| **조사 대상** | 벽에 걸린 사진들 / 방명록 |
| **접근** | 전원 |
| **숨겨진 것** | 오래된 사진 한 장에 **20년 전 섬에서 일하던 사람들**이 찍혀 있습니다. 그중 하나가 **아서 웨이드**입니다. **아무도 알아보지 못합니다** — 20년이 지났고, 그는 많이 변했으니까요 |

> **여기가 관찰(觀察)의 무대입니다.** 사람들이 모여 있으므로, 누가 누구를 피하는지 볼 수 있습니다.

## ③ 식당

| | |
| --- | --- |
| **조사 대상** | 좌석 배치표 |
| **접근** | 전원 |
| **숨겨진 것** | 🔑 **좌석 배치표는 마이클이 손으로 썼습니다.** CASE 1의 필체 대조에 쓸 견본이 여기 또 있습니다 |

> 배에서 견본을 못 구한 플레이어를 위한 **두 번째 기회**입니다. 게임이 단서를 아예 막지 않는다는 원칙([07번](./07_CASE1_인물별_진실과_거짓말.md) §6-B)의 실행입니다.

## ④ 서재 — 배우의 공간

책과 서류. 그리고 오래 비어 있던 냄새.

| | |
| --- | --- |
| **조사 대상** | 계약서 묶음 / 책상 / 벽난로 |
| **접근** | **에드워드**(권한) · **알렉산더**를 설득했을 때 |
| **숨겨진 것** | 오래된 계약서에 **A. 모건이 책임자로 서명**되어 있습니다 (필체 #2 = 마이클). 그리고 벽난로에 **태우다 만 종이 조각**이 있습니다 |

> **태우다 만 것이 무엇인지**는 결말에 따라 다릅니다. 깊이 판 회차에서는 **배우의 유서 일부**입니다.

## ⑤ 객실 구역

여덟 명이 각자 방을 배정받습니다.

| | |
| --- | --- |
| **조사 대상** | 각자의 짐 (누구 방에 들어가느냐가 선택) |
| **접근** | **자기 방은 전원. 남의 방은 들키면 끝장** |
| **숨겨진 것** | **마이클의 방에 리처드의 노트가 있습니다.** 아직 태우지 못했습니다 — 섬에는 그럴 곳이 마땅치 않았고, 사람들이 계속 붙어 있었으니까요 |

> ⚠️ **이건 게임에서 가장 위험한 조사입니다.** 성공하면 결정적이지만, **들키면 마이클이 경계 상태로 바뀌고 CASE 2의 결말이 나빠집니다.**
> 몰래 들어갈 수 있는 것은 **에밀리**뿐입니다. 아무도 그녀를 신경 쓰지 않으니까요.

## ⑥ 관리동 (별채)

저택에서 조금 떨어진 건물. 손님이 갈 이유가 없는 곳입니다.

### ⑥-a 사무실

| | |
| --- | --- |
| **조사 대상** | **섬 작업 일지** / 물품 대장 |
| **접근** | **에드워드**(권한) · **에밀리**(눈에 안 띔) |
| **숨겨진 것** | 🔑 **작업 일지에 매일 "A. 모건" 서명이 있습니다.** 최근 날짜까지 계속. **필체 #3입니다** |

> **이것이 CASE 2의 첫 번째 충격입니다.**
> 헨리의 오래된 기록에서 세 종류의 필체를 확인한 플레이어가, **그중 하나가 지금도 매일 쓰이고 있다**는 것을 발견합니다.
>
> **A. 모건은 과거형이 아니었습니다.**

### 🔑 그리고 헨리의 오래된 출입기록과 대조하면

헨리 콜이 가지고 있는 20년 전 기록의 앞부분에는 다른 서명이 반복해서 나옵니다.

```
  A. Wade
  A. Wade
  A. Wade
  ...
  ← 사고가 있던 날
  A. Morgan
  A. Morgan
  A. Morgan
```

**같은 날을 경계로 성만 바뀝니다.**

> 헨리는 3년 동안 그 서명을 받아 적어 왔습니다. 급하게 이름을 지어내야 했을 때, 그의 손에 남아 있던 것이 그 모양이었습니다.
> **아서 웨이드는 자기 서명의 절반만 잃었습니다.**

이것이 **그의 원래 이름을 알아내는 유일한 경로**입니다. (대조 동사)

### ⑥-b 아서 웨이드의 방

작고 정갈합니다. 20년째 같은 방입니다.

| | |
| --- | --- |
| **조사 대상** | 침대 옆 상자 |
| **접근** | **에밀리**(몰래) · **엘레나**(그가 문을 열어줌) |
| **숨겨진 것** | 상자 안에 **오래된 물건 몇 개.** 그리고 **여배우가 D-3에 두고 간 것** |

> 🔑 **엘레나만 문이 열립니다.**
> 여배우가 죽기 사흘 전 이 방에 왔었습니다. **그는 그녀를 기억합니다.**
> 엘레나가 친구 이야기를 꺼내는 순간 — 그녀가 유일하게 할 수 있는 일입니다 — 그는 처음으로 말을 합니다.

## ⑦ 정원

| | |
| --- | --- |
| **조사 대상** | 손질 상태 |
| **접근** | 전원 |
| **숨겨진 것** | **한 자리만 유독 오래 손질되어 있습니다.** 20년째 누군가 돌보고 있습니다 |

> 아서가 매일 돌보는 자리입니다. 물어보면 이렇게 답합니다.
>
> > "여기는 그냥 그래야 해서요."
>
> 🔑 **거기엔 아무것도 없습니다.** 20년 전에 누군가 그에게 시킨 일이고, 그는 한 번도 그만두지 않았을 뿐입니다.
> **시킨 사람은 이미 잊었고, 시킨 이유도 남아 있지 않습니다.**

## ⑧ 절벽 (전망대) — 이 섬의 중심 🔑

# 3. 한 장소에서 세 번

**절벽에서 이 이야기의 세 사건이 겹칩니다.**

| 시점 | 일 |
| --- | --- |
| **20년 전** | 폭풍 속에서 배우가 여기 올라가려 했고, **아서 웨이드가 말렸습니다.** 실랑이 끝에 밀쳐져 넘어졌고, 머리를 부딪쳤습니다 |
| **2년 전** | **배우가 여기서 스스로 목숨을 끊었습니다.** 자기가 사람을 망가뜨린 바로 그 자리에서 |
| **지금** | 결말에 따라, **아서 웨이드가 여기서 떨어집니다.** 사고로 처리됩니다 |

그리고 **에밀리가 20년 전 22시 07분에 찍은 사진이 바로 이 자리입니다.**

> 플레이어는 사진 속 그 장소에 실제로 서게 됩니다. **그리고 그때 사진을 다시 보면, 프레임 구석에 두 사람의 형체가 있습니다.**

# 4. 배우의 시신

절벽 아래 바위 사이에 있습니다. 2년 동안.

**마이클이 옮기지 않았습니다.** 옮길 수 없었습니다 — 내려갈 방법이 없었으니까요. 그가 한 일은 **아무에게도 말하지 않은 것**뿐입니다.

| 조건 | 결과 |
| --- | --- |
| 그냥 절벽을 조사 | 난간이 오래전에 부서졌다가 대충 고쳐진 흔적 |
| **에밀리로 절벽을 조사** | 아래쪽 바위 틈에 **무언가가 있다**는 것을 알아챕니다. 무엇인지는 알 수 없습니다 |
| **깊은 회차 + 에드워드** | 확인을 요청할 수 있습니다. **구조선이 온 뒤에** |

> ⚠️ **CASE 2 안에서는 시신을 확인할 수 없습니다.** 폭풍이고, 내려갈 장비가 없습니다.
> 플레이어는 **"저기 무언가가 있다"** 는 것만 알고 섬을 떠납니다.
>
> 이것이 마지막 혼잣말과 맞물립니다. **알아챘지만 확인하지 못한 것 하나를 안고 나가는 것**이 이 게임의 기본 형태입니다.

## 이 표가 말하는 것

* **에드워드**는 문을 열 수 있지만 **사람 마음은 못 엽니다.** 아서는 경찰 앞에서 입을 다뭅니다
* **엘레나**는 문을 못 열지만 **아서가 그녀에게는 열어줍니다.** 유일하게
* **에밀리**는 어디든 갈 수 있습니다. **아무도 그녀를 보지 않기 때문입니다** — 그리고 그게 그녀의 20년짜리 습관이기도 합니다
* **토머스**는 장소가 아니라 **사람**을 통해 움직입니다. 그의 무대는 응접실입니다

> **네 명이 각각 다른 섬을 걷습니다.**

# 6. CASE 1과 다른 점

| | CASE 1 (배) | CASE 2 (섬) |
| --- | --- | --- |
| **공간** | 좁고 닫혀 있음 | 넓고 흩어져 있음 |
| **시간** | 섬에 도착할 때까지 | 구조선이 올 때까지 |
| **긴장** | **누가 죽였나** | **누가 죽을 것인가** |
| **적** | 이미 벌어진 일 | **아직 벌어지지 않은 일** |

> **CASE 1은 과거를 파는 이야기이고, CASE 2는 다음 죽음을 막는 이야기입니다.**
> 그런데 플레이어는 **막아야 할 대상이 누구인지도 모르는 채** 시작합니다.
