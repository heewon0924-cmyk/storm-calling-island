# 「폭풍을 부르는 섬 이야기」 — MASTER 설정 문서

## 0. 이 문서의 목적

이 문서는 새 대화에서 게임 기획을 이어가기 위한 **기준 문서**입니다.

앞으로 이 문서를 기준으로 설정을 유지합니다.

* 이미 정해진 내용은 임의로 변경하지 않는다.
* 아직 정하지 않은 내용은 임의로 확정하지 않는다.
* 새로운 아이디어는 기존 설정과 구분해서 제안한다.
* 설정이 충돌할 경우 먼저 기존 확정 설정을 우선한다.
* 특히 **MASTER TRUTH(실제 사건)**와 **캐릭터가 알고 있는 정보**를 절대 섞지 않는다.

---

# 1. 게임 기본 콘셉트

### 제목

**「폭풍을 부르는 섬 이야기」**

제목의 의미는 두 가지입니다.

1. 실제로 폭풍이 몰아치는 섬과 사건
2. 과거의 사건을 다시 세상에 끌어내는 사람들

### 장르

현실적인 **미스터리 / 추리 / 탐정 게임**

초자연적인 요소가 사건의 핵심이 되지 않습니다.

### 핵심 특징

하나의 큰 사건을 여러 인물의 시점으로 경험합니다.

플레이어는 캐릭터마다 다른 정보를 얻습니다.

같은 사건이라도 캐릭터에 따라:

* 직접 본 것
* 들은 것
* 추측한 것
* 오해한 것
* 숨기고 있는 것

이 서로 다릅니다.

따라서 플레이어는 여러 캐릭터의 플레이를 통해 전체 진실을 조립하게 됩니다.

---

# 2. 게임의 큰 이야기

세계적으로 유명한 전설적인 배우가 있습니다.

배우는 전성기이며 아직 젊고, 엄청난 인기를 누리고 있습니다.

그런 배우가 과거 연인이었던 유명 여배우의 살인사건에서 주요 용의자로 지목됩니다.

하지만 결정적인 증거가 발견되지 않아 배우는 처벌받지 않습니다.

경찰 조사를 받고 집으로 돌아간 배우는 갑자기 **아무런 설명 없이 사라집니다.**

은퇴 선언도 없고, 작별도 없습니다.

시간이 지난 후 배우의 이름으로 약 8명에게 의문의 초대장이 도착합니다.

초대 대상에는 과거 여배우 살인사건과 관련된 사람들이 포함되어 있습니다.

초대받은 사람들은 배우의 개인 섬으로 향하는 전용선에 탑승합니다.

하지만 정작 배우는 배에도, 섬에도 모습을 드러내지 않습니다.

그리고 섬으로 향하던 중 **섬의 관리인 Richard Bennett가 살해됩니다.**

# 3. CASE 구조

## CASE 1

**사건:** 전용선에서 Richard Bennett 살해

주요 질문:

1. **누가 Richard를 죽였는가?**
2. **Richard와 죽은 여배우는 어떤 관계였는가?**
3. **Richard는 왜 죽어야 했는가?**

CASE 1에서는 1번을 해결합니다.

2번은 상당 부분 밝혀집니다.

하지만 3번의 완전한 답은 CASE 2 이후까지 남겨둡니다.

즉 플레이어가 CASE 1을 끝내면서:

> “아, Richard가 이걸 알고 있었기 때문에 죽였구나.”

정도까지는 이해할 수 있지만,

> “그렇다면 왜 과거의 일을 그렇게까지 숨겨야 했는가?”

라는 더 큰 의문은 CASE 2로 이어집니다.

---

## CASE 2

배우의 개인 섬에서 별도의 사건이 발생합니다.

CASE 2를 통해:

* Richard의 과거
* 섬에서 발생했던 오래된 사건
* A. Morgan의 정체
* 여배우 살인사건의 진실
* 배우가 사라진 이유
* Richard가 반드시 제거되어야 했던 이유

등이 서로 연결됩니다.

CASE 1의 범인, CASE 2의 범인, 과거 여배우 살인사건의 범인은 **서로 다를 수도 있습니다.**

다만 각각의 사건은 더 큰 하나의 이유로 연결됩니다.

# 6. A. Morgan

현재 매우 중요한 미스터리 요소입니다.

### 핵심 설정

**A. Morgan은 실존 인물이 아닐 가능성이 높습니다.**

오래된 섬 기록에서 반복해서 등장하지만 공식적인 인물 기록이 없습니다.

더 중요한 점은:

* 기록마다 필체가 다름
* 여러 사람이 같은 이름을 사용한 흔적
* 특정 사건의 책임자로 반복해서 등장

한다는 것입니다.

즉 A. Morgan은 실제 사람이라기보다:

> **책임을 떠넘기기 위해 만들어진 가상의 책임자**

에 가깝습니다.

처음에는 작은 사건의 책임을 피하기 위해 만들어졌지만 시간이 지나면서 여러 사람이 서로 다른 목적으로 같은 이름을 사용하게 됩니다.

예:

* 자신의 실수를 숨기기 위해
* 다른 사람을 보호하기 위해
* 돈이나 이익을 위해
* 과거 사건을 은폐하기 위해

작은 거짓말들이 쌓여 거대한 거짓말이 됩니다.

# 7. 과거 섬 사건

배우가 유명해지기 전 발생한 사건입니다.

폭풍이 몰아치던 밤 여러 사람이 섬에 있었습니다.

한 사람이 크게 다치거나 사망한 것으로 공식 기록에 남았습니다.

공식적인 설명:

> **악천후로 인한 사고**

하지만 실제 상황에는 여러 가지 모순이 있습니다.

* 사고 시각이 맞지 않음
* 일부 사람의 행적이 기록에서 사라짐
* 누군가의 이름이 공식 기록에서 삭제됨
* 여러 사람이 서로 다른 작은 거짓말을 함
* 사고 현장에서 중요한 물건이 이동됨
* A. Morgan이라는 가상의 책임자가 만들어짐

그리고 당시 사건의 진실을 알고 있는 사람들이 각자 일부만 기억하거나 숨기고 있습니다.

# 8. CASE 1 MASTER 설계 원칙

가장 중요한 제작 원칙입니다.

## 먼저 MASTER TRUTH를 만든다.

캐릭터별 정보를 먼저 만들지 않습니다.

먼저 작가만 알고 있는:

> **“그날 실제로 무슨 일이 있었는가?”**

를 완성합니다.

MASTER에는:

* 실제 시간
* 실제 장소
* 실제 이동 경로
