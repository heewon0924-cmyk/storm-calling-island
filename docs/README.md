## 상태 표기 규칙

새로운 설정을 추가하거나 논의할 때는 아래로 상태를 구분합니다.

* **[확정]** — 지금까지 합의된 설정. 임의로 변경하지 않는다.
* **[보류]** — 방향은 잡혔지만 세부 내용은 아직 결정하지 않았다.
* **[제안]** — 향후 검토할 아이디어. 확정 설정으로 취급하지 않는다.
* **[폐기]** — 이전에 나왔으나 현재 사용하지 않는 설정.
* **[의도적 보류]** — 비워두는 것 자체가 설계인 것. 채우면 안 된다.

기존 [확정] 설정과 새로운 아이디어가 충돌할 경우, **새로운 아이디어를 우선하지 않는다.**

그리고 특히 **MASTER TRUTH(실제 사건)** 와 **캐릭터가 알고 있는 정보** 를 절대 섞지 않는다.
